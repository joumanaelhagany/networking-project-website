About This Project

This website was created for a Computer Networking course project. It explains important networking concepts such as DNS, IP addressing, and HTTPS communication.

Project 2 Improvements

In Project 2, the website was enhanced with a feedback page so users can interact with the site. Security was improved through safer handling of user input, and performance was improved by using a lazy-loaded image on the feedback page.

These improvements help make the website more interactive, more secure, and better optimized.
